# ระบบฝึกทำข้อสอบการพยาบาลออนไลน์ (Nursing Exam Practice System)

ระบบฝึกทำข้อสอบออนไลน์จำลองสนามสอบจริง สำหรับเตรียมสอบบรรจุข้าราชการ/พนักงานกระทรวงสาธารณสุข ตำแหน่งพยาบาลวิชาชีพปฏิบัติการ (อิงโครงสร้างและมาตรฐานแนวข้อสอบ รพ.สรรพสิทธิประสงค์ จ.อุบลราชธานี)

---

## 📌 จุดเด่นและคุณสมบัติของระบบ

1. **คลังข้อสอบมาตรฐาน 9 วิชา รวม 900 ข้อ (วิชาละ 100 ข้อ)**
   - ข้อสอบอิงสถานการณ์ทางคลินิก (Scenario-based) 4 ตัวเลือก (ก, ข, ค, ง) พร้อมเฉลยละเอียดและหลักวิชาการ
   - ทุกวิชาเฉลยกระจายตัวเลือก ก/ข/ค/ง เท่ากันอย่างแม่นยำ **25 / 25 / 25 / 25 ข้อ**
   - ตัวเลือกลวงมีคุณภาพ สมดุลความยาวข้อความ ไม่สามารถเดาคำตอบจากความยาวได้
2. **ระบบสุ่มจัดชุดสอบจำลอง (270 ข้อ)**
   - สุ่มวิชาละ **30 ข้อ** รวม 9 วิชา = **270 ข้อ** ต่อรอบการสอบ
   - สุ่มลำดับตัวเลือก (Choice Shuffling) ป้องกันการจำตำแหน่ง
   - **ไม่จำกัดเวลา** เพื่อให้ฝึกคิดวิเคราะห์อย่างเต็มที่
   - เกณฑ์ผ่าน **70%** (189 / 270 คะแนน)
3. **ระบบป้องกันการโกงและความปลอดภัย (Anti-Cheat & Security)**
   - **Single-Session Enforcement**: 1 บัญชีเข้าใช้งานได้พร้อมกันเพียง 1 อุปกรณ์เท่านั้น หากมีการล็อกอินซ้อน ระบบจะปฏิเสธด้วยรหัส `409 Conflict` ทันที
   - **No Answer Leaks**: ฝั่งเซิร์ฟเวอร์ไม่ส่งเฉลยและคำอธิบายไปยังเบราว์เซอร์ระหว่างสอบ จนกว่าผู้สอบจะกดยืนยันส่งข้อสอบเท่านั้น
   - **Auto-Save & Resume**: บันทึกคำตอบและสถานะการทำเครื่องหมาย (Flag) ทุกข้ออัตโนมัติ หากเน็ตหลุดหรือปิดเว็บ สามารถกลับมาทำต่อได้
4. **ระบบสรุปผลและเฉลยละเอียด (Post-Exam Review)**
   - วงแหวนแสดงคะแนนรวม ร้อยละ และสถานะผ่าน/ไม่ผ่าน
   - กราฟแท่งเปรียบเทียบจุดแข็ง-จุดอ่อนรายวิชาเทียบกับเกณฑ์ 70%
   - แท็บกรองข้อสอบ: ดูทั้งหมด / ดูเฉพาะข้อที่ตอบผิด / ดูเฉพาะข้อที่ตอบถูก / ดูแยกตามวิชา
5. **ระบบผู้ดูแลระบบ (Admin Management & Analytics)**
   - แดชบอร์ดสถิติผู้เข้าสอบ คะแนนเฉลี่ยรวม คะแนนเฉลี่ยรายวิชา
   - จัดการผู้ใช้งาน: สร้างบัญชี, แก้ไข, เปลี่ยนรหัสผ่าน, ระงับบัญชี, บังคับออกจากระบบ (Force Logout)
   - ส่งออกผลคะแนนทุกวิชาเป็นไฟล์ **CSV (UTF-8 BOM)** เปิดด้วย Microsoft Excel ภาษาไทยได้ทันทีไม่เพี้ยน

## 🚀 วิธีติดตั้งและเปิดใช้งานในเครื่อง (Local Setup)

### 1. ติดตั้งไลบรารี
```powershell
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. ตรวจสอบความสมบูรณ์ของคลังข้อสอบ
```powershell
.venv\Scripts\python.exe tools/validate_questions.py
```
*(ผลลัพธ์ต้องแสดง `รวม 900 ข้อ, 9 วิชา | ผลตรวจ: ผ่าน [OK]`)*

### 3. รันการทดสอบระบบ (Automated Tests)
```powershell
.venv\Scripts\python.exe -m unittest tests/test_api.py
```

### 4. เริ่มต้นเซิร์ฟเวอร์
```powershell
.venv\Scripts\python.exe app.py
```
เปิดเบราว์เซอร์ไปที่: **`http://127.0.0.1:5000`**

## 🔑 ข้อมูลบัญชีผู้ดูแลระบบเริ่มต้น (Default Admin)

เมื่อเริ่มระบบครั้งแรก ระบบจะสร้างบัญชีแอดมินให้อัตโนมัติ:
- **ชื่อผู้ใช้ (Username):** `admin`
- **รหัสผ่าน (Password):** ดูได้จากหน้าต่าง Terminal / Log ตอนเริ่มระบบครั้งแรก (หรือกำหนดเองผ่าน Environment Variable `ADMIN_PASSWORD`)

## ⚙️ ตัวแปรสภาพแวดล้อม (Environment Variables)

| ตัวแปร | ค่าเริ่มต้น | รายละเอียด |
| :--- | :---: | :--- |
| `DATA_DIR` | `./data` | ไดเรกทอรีจัดเก็บไฟล์ฐานข้อมูล `nursing.db` (บน Render ให้ชี้ไปยัง Persistent Disk) |
| `ADMIN_USERNAME` | `admin` | ชื่อผู้ใช้บัญชีผู้ดูแลระบบเริ่มต้น |
| `ADMIN_PASSWORD` | สุ่มอัตโนมัติ | รหัสผ่านผู้ดูแลระบบเริ่มต้น |
| `PER_SUBJECT` | `30` | จำนวนข้อที่สุ่มต่อวิชาในแต่ละชุดสอบ (9 วิชา x 30 = 270 ข้อ) |
| `PASS_PERCENT` | `70` | เกณฑ์คะแนนขั้นต่ำที่ถือว่าผ่าน (ร้อยละ 70) |
| `SESSION_TIMEOUT` | `120` | วินาทีที่ตรวจจับการไม่มีกิจกรรมเพื่อเคลียร์ session ผู้ใช้ |
| `COOKIE_SECURE` | `0` | ตั้งเป็น `1` เมื่อขึ้น Production ด้วย HTTPS เพื่อเปิด Secure Cookie |
| `PORT` | `5000` | พอร์ตสำหรับรันเว็บเซิร์ฟเวอร์ |

## 🌐 คำแนะนำการนำขึ้น Production (Render / Cloud VPS)

สำหรับการนำขึ้น Production บน Linux/Render:
1. ใช้คำสั่ง Start Command ด้วย Gunicorn:
   ```bash
   gunicorn -w 1 --threads 8 -b 0.0.0.0:$PORT app:app
   ```
2. ต่อเชื่อม **Persistent Disk** เข้ากับโฟลเดอร์ที่ระบุใน `DATA_DIR` (เช่น `/var/data`) เพื่อไม่ให้ข้อมูลผู้ใช้และประวัติการสอบสูญหายเมื่อรีสตาร์ตเซิร์ฟเวอร์
3. กำหนด `COOKIE_SECURE=1` เพื่อความปลอดภัยของคุกกี้บนโปรโตคอล HTTPS
